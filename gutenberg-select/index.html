Gutenberg Select - Home Scholar Library

Gutenberg Select is a curated collection of the better Gutenberg offerings for the self learner. This is a wider and separate collection from the Home Scholar Library proper. Inclusion here is a fast decision based on subjec and titles from the approx 80,000 current books on Gutenberg.

Each entry links straight out to its own description page on Gutenberg.org. check out BetterGutenberg.org for companion titles. I am not able to easily make an automatic cross reference at this time.
